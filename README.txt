LEONIDAS CATALOGUE 2027 — SITE WEB

Contenu:
- index.html : page de consultation avec navigation page par page.
- catalogue.pdf : PDF original.

Publication:
1. Décompressez ce dossier.
2. Déposez les deux fichiers dans un hébergement statique qui accepte les fichiers PDF de 70 MB.
3. Activez l'accès public.
4. Testez le lien sur un téléphone en navigation privée.
5. Le QR code doit pointer vers l'adresse publique de index.html.

Le lecteur utilise PDF.js et peut demander les pages par plages d'octets si l'hébergeur prend en charge les requêtes HTTP Range.
Le chargement progressif dépend de l'hébergement et de la structure du PDF.
